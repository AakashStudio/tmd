# Oracle Sans Font Integration Directory

Place the licensed Oracle Sans web font files in this directory:
- `OracleSans-Regular.woff2` (Weight 400)
- `OracleSans-Medium.woff2` (Weight 500)
- `OracleSans-SemiBold.woff2` (Weight 600)
- `OracleSans-Bold.woff2` (Weight 700)
- `OracleSans-Black.woff2` (Weight 900)

These are linked directly in `src/app/globals.css` via `@font-face`.
